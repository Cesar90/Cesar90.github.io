# César Cordero — Developer Portfolio

Personal portfolio website showcasing my experience, technical skills, and selected projects as a Full-Stack Developer.

The portfolio is built from scratch with React, TypeScript, Webpack, Tailwind CSS, and shadcn/ui.

## 🚀 Live Website

**[cesar90.github.io](https://cesar90.github.io)**

## 👨‍💻 About

I'm a Full-Stack Developer with more than 10 years of experience building web applications, SaaS platforms, eCommerce solutions, APIs, and business systems.

My experience includes frontend development, backend architecture, database design, DevOps, cloud infrastructure, CI/CD, monitoring, and application performance.
